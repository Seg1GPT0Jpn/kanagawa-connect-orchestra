# 協賛制度・会計報告 運用手順（公開対象外）

代表が未成年のため、お金に関わる最終確認は **保護者などの信頼できる成人（成人の確認者）** と一緒に行います。
この手順書は `_tools/` にあり、Firebase Hosting では公開されません。

## 1. 現在の状態（第1段階）

- 協賛ページは「協賛制度準備中」と表示しています。
- 振込先・支払いボタン・決済リンクは **どこにも実装していません**。
- 申込みフォームはありますが、成人の確認者が受付を開始するまで表示されず、送信もサーバー側（Security Rules）で拒否されます。
- 成人の確認者は `firestore.rules` の `isReviewer()` に **まだ登録されていません**。登録されるまで、次の操作は誰にもできません。
  - 会計報告を「確認済み」にする・公開する・公開後に訂正する
  - 返金の承認、入金済みの協賛の取消
  - 掲載特典の確定、申込み受付の開始

## 2. 受け入れ開始までに成人と確認すること（チェックリスト）

- [ ] 成人の確認者を決め、その人の Google アカウント（運営管理者とは別のアカウント）を `firestore.rules` の `isReviewer()` に追加してデプロイする
- [ ] Firebase プロジェクトの「オーナー」権限を成人が持つ（未成年だけで Security Rules を変更できない状態にする）
- [ ] 団体活動用の口座を開設する（名義・開設方法・通帳の管理者を決める）
- [ ] 受け入れ方法（銀行振込など）と手数料の負担を決める
- [ ] オンライン決済を使う場合は、利用規約・未成年や任意団体の利用可否・手数料・返金・本人確認・税務を確認し、別途実装計画を立てる（現在は未実装）
- [ ] 税務上の扱い（寄附と、広告掲載などの対価を伴う協賛の区別）を確認する
- [ ] 会計年度の区切りを決める
- [ ] 個人情報の保存期間を決め、協賛制度規定（`sponsor-policy.html`、`_tools/build_site.py` の `POLICY`）の「（案）」を確定させる
- [ ] 掲載特典の文言を管理画面で入力し、成人の確認者が「確認済み」にする
- [ ] 協賛制度規定の「準備中（案）」表示と制定日を更新する
- [ ] 以上が済んでから、成人の確認者が管理画面で「申込み受付を開始」する

## 3. 協賛の流れ（管理画面 `sponsor-admin.html`）

1. 申込みが届いたら「記録を作成」（同じ申込みから2件は作れません）
2. メールで支払い方法を案内し、状態を「入金確認待ち」にする
3. **通帳・入金記録で実際の入金を確認してから**、入金額と入金確認日を入れて「入金確認済み」にする
   - フォームの送信や本人からの連絡だけで入金済みにしないこと
   - 入金額が協賛金額（口数×単価）と一致しない場合は掲載できません
4. 掲載する場合は、同意の記録・掲載開始日を確認して「掲載中」にする（公開一覧に自動で反映）
5. 掲載期間が終わったら「掲載終了」にする（公開一覧から自動で消えます）
6. 取消・返金は成人の確認者が行う（元の記録・履歴は消えません）

ロゴを掲載する場合は、画像を確認してから `images/sponsors/` に置き（png・jpg・webp、英小文字・数字・-_ のファイル名）、記録に「ロゴのファイル名」を入力してデプロイします。SVG やほかのサイトの画像URLは使えません。

## 4. 会計報告（管理画面 `report-admin.html`）

1. 運営管理者が、通帳・領収書などの実際の記録から下書きを作る（未確認の数値・見込みの金額は入れない）
2. 「協賛金収入」が協賛記録の入金確認済み合計と一致するか、画面の警告で確認する（二重計上・記録漏れの確認）
3. 「成人の確認者に確認を依頼」
4. 成人の確認者が記録と照合し「確認済みにする」→「ウェブサイトで公開する」
5. 公開後に誤りが見つかったら、成人の確認者が数値を直し、訂正の内容を入れて保存する（訂正履歴として公開され、消せません）
6. 個人情報が載ってしまった場合などは、運営管理者でも「公開を取り下げる」ことができます

公開資料には、個人名・口座番号・メールアドレス・取引IDを書かないでください（メールアドレスや7桁以上の数字はサーバー側でも拒否します）。取引明細や領収書は公開しません。

## 5. 個人情報

- 申込み・協賛記録は運営管理者と成人の確認者だけが読めます（Security Rules で制限）
- 保存期間を過ぎた申込み、本人から削除を依頼された申込みは、管理画面から削除します
- 協賛記録の連絡先（担当者名・メールアドレス）は、保存期間を過ぎたら空欄に変更します（会計の根拠となる金額・日付・管理IDは残ります）
- 備考に口座番号・住所などを書かないでください

## 6. 募集の停止

今後1年分の運営資金と合理的な予備費を確保できる見通しになったら、成人の確認者と相談して新規募集の一時停止・終了を検討します。
受付の停止は、運営管理者も管理画面からできます。停止後も会計報告と約束した掲載は続けます。

## 7. 変更するとき

判定条件は `firestore.rules`・`_tools/firebase/src/sponsor-logic.js`・`_tools/firebase/test/` の3か所にあります。
変更したら `_tools/firebase` で `npm test` を実行し、すべて通ることを確認してからデプロイしてください（Java が必要です）。
