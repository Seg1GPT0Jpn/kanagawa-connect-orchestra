# 実機での確認表（公開前に必ず）

自動テストでは確かめられない、音・マイク・同期の動きを実機で確かめます。
結果は「○／×／気づいたこと」を書き込み、× があれば開発側に伝えてください。

確かめる端末（できれば全部）：

| 端末 | OS・ブラウザ | 担当 | 日付 |
| --- | --- | --- | --- |
| Android スマホ | Android ／ アプリ版 |  |  |
| Android スマホ | Chrome（Web 版） |  |  |
| iPhone | iOS ／ アプリ版 |  |  |
| iPhone | Safari（Web 版） |  |  |
| パソコン | Chrome・Edge（Web 版） |  |  |

## 1. 音を鳴らす（道具タブ）

各端末で、**内蔵スピーカー**・**有線イヤホン**・**Bluetooth イヤホン**の3通りで確かめます。

| 確かめること | 期待する動き | 結果 |
| --- | --- | --- |
| 右上の「音の設定・テスト」→「テスト音を鳴らす」 | クリックが3回聞こえる |  |
| メトロノーム 60・120・240 BPM を1分ずつ | 音が途切れず、テンポが揺れない |  |
| メトロノームの拍の光と音 | ずれが気にならない（Bluetooth は遅れることがある） |  |
| クリックトラック：テンポ・拍子が変わる区間 | 区間の変わり目で音が詰まったり抜けたりしない |  |
| 基準音：音を変える・音色を変える・止める | プツッという音が出ない、止めるとすぐ止まる |  |
| iPhone：消音スイッチを入れたまま鳴らす | 鳴る（Safari 17 未満は鳴らないことがある） |  |
| 音量のつまみ（ミキサー）を 0 → 100% | それぞれの音だけが変わる |  |
| 鳴らしている途中でホーム画面に戻り、また開く | 音は止まっている。もう一度ボタンで鳴らせる |  |
| 鳴らしている途中に電話・通知・アラームが来る | アプリが固まらない。終わった後もう一度鳴らせる |  |

## 2. マイク（チューナー・録音）

| 確かめること | 期待する動き | 結果 |
| --- | --- | --- |
| 初めてチューナーを使う | マイクの許可を聞かれる |  |
| 許可を**拒否**する | 「マイクの使用が許可されていません…」と出て、ほかの機能は使える |  |
| 拒否のあと、端末の設定で許可して戻る | もう一度「はじめる」で使える |  |
| 楽器で B♭（記譜 C）を吹く | 音名が合っていて、表示が暴れない |  |
| 30cm・1m・3m 離れて吹く | 遠いほど反応が遅く・途切れやすくなるが、音名は合う |  |
| 録音 30 秒 | 途中で音が切れない。最後まで録れて分析が出る |  |
| 録音の途中でホーム画面に戻る | 録音は止まり、そこまでで分析される |  |
| 録音の「信頼度」 | 静かな部屋で近くから吹くと「高い」、遠い・うるさいと下がる |  |
| Bluetooth イヤホンをつないだまま録音 | 端末のマイクで録れる（イヤホンのマイクに切り替わらないか） |  |
| チューナーを使いながら基準音を鳴らす | 両方使える（基準音をマイクが拾うのは正常） |  |

## 3. 同期と復旧（アカウントタブ・記録タブ）

ログインして使う場合に確かめます。2台の端末（A・B）を用意します。

| 確かめること | 期待する動き | 結果 |
| --- | --- | --- |
| A で練習を記録 → B を開く | B にも出る |  |
| 機内モードの A で記録を3件・メモを編集 → 通信を戻す | 3件とメモが B に届く |  |
| A・B の両方で、同じ記録のメモを機内モードで編集 → 両方の通信を戻す | 後から編集した方が残る |  |
| A で記録を削除 → 「元に戻す」 | 戻る。B でも消えずに残っている |  |
| A で削除 → B で消えたのを確認 → A の「削除した記録」から戻す | B にも戻る |  |
| ログアウト → 再ログイン | 記録がそのまま見える |  |
| 新しい端末（または Web）でログイン | 記録がすべて届く |  |
| 記録タブ「︙」→ バックアップを書き出す → アプリを入れ直す（または別のブラウザ）→ 読み込む | 記録と録音の分析結果が戻る |  |
| 端末の時計を 1 時間遅らせて記録を編集 → 時計を戻す | 編集が消えない（※ 別の端末の編集と競合すると、時計の進んだ端末が勝つことがある） |  |

### 時計のずれについての注意

同期では、同じ記録を2台で編集したとき「編集した時刻が新しい方」を残します。端末の時計が大きくずれていると、意図しない方が残ることがあります。端末の「日付と時刻を自動で合わせる」をオンにしておいてください。
同じ端末での編集は、時計が戻っていても必ず新しい編集が残るようにしてあります。
