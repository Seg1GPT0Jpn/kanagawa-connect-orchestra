# プロ奏者の練習法と『アーバン』の調査 ― アプリへの反映

運営からいただいた調査（プロのトランペット奏者本人の発言、大学教員・指導者の練習法、『アーバン』の版と構成）を分析し、
練習メニューにどう反映したかをまとめます。調査の出典・数値は、いただいた資料のものをそのまま使っています
（このアプリの開発で個別に裏取りはしていません）。

## 1. 調査から読み取れること

| 観点 | 調査の内容 | アプリでの扱い |
|---|---|---|
| 練習の分野 | 音の準備（呼吸・バズィング）／音色・音程／柔軟性／指の技術／アーティキュレーション／音程・アタック／音楽表現／振り返り | メニューの各項目と Arban の章に「何を鍛えるか」を表示 |
| 毎日同じではない | 「その日に改善したい技術を選ぶ」（Brian Shaw、Markus Stockhausen、指導記事） | **Arban を章ごとに分け、0分＝お休みを許可**。「今日の重点」のおすすめ |
| 時間に合わせて短縮 | Michael Sachs は45分のウォームアップに20・30・10・5分の短縮版を用意 | おすすめに「短め（45分）」「長め（95分）」 |
| 基礎と曲の配分 | 基礎に全体の50〜70%（Eric Sperry）。ITG の1時間例では曲・レパートリーが約33% | 下の「提案」2 |
| 短い区切り | ITG の例は各項目2〜8分。Chris Martin の朝45分は5・20・10・10分の区切り（休憩込み） | タイマーは項目ごとに区切って計る |
| 疲労・負荷 | 高音・大音量の翌日は柔らかい音で（Brian Shaw）。忙しい時期は練習量を減らす方が安定（Steve Hendrickson） | おすすめ「音色・柔軟性」、メニュー画面に「疲れや痛みが出たら無理をしない」 |
| 合奏・本番も演奏時間 | オーケストラ奏者はリハーサル・本番も唇の負荷になる（Chris Martin） | 下の「提案」5 |

## 2. 『アーバン』を章ごとに追加

1893年 E. F. Goldman 編集版の分類（オンラインカタログ。収録数は合計805、版によって異なる）で12の章に分けました。

| 章（アプリでの名前） | 収録数 | 鍛えること |
|---|---:|---|
| 初歩練習（First Studies） | 50 | 音の長さ・音程・運指、リズムと発音の連携 |
| シンコペーション | 38 | 拍の強弱、裏拍・拍をまたぐリズム |
| スラー（Slurring / Legato） | 69 | 息と唇の協調、滑らかな音のつながり |
| 音階 | 78 | 全調への対応、指の均一さ |
| 半音階 | 31 | 半音の動きを均一なリズム・音色で |
| 装飾音 | 88 | ターン・前打音・トリル・モルデント |
| 音程・跳躍（Intervals・分散和音） | 62 | 広い音程を正確に、和声の理解 |
| タンギング | 145 | シングル・ダブル・トリプル。粒・アクセント・均一さ |
| フレージング（旋律） | 150 | フレーズの山・呼吸位置・音の行き先 |
| 二重奏 | 68 | 拍の共有、相手を聴く |
| 性格的練習曲 | 14 | 学んだ技術を1曲の中で使う |
| 幻想曲・変奏曲 | 12 | ソロ作品としての表現と技巧 |

- **Arban の合計は通常モードで 20〜40分**（指示書のルール。20分・10分モードでは 0〜15分・0〜10分）。0分の章はタイマーで飛ばします。
- 監査は「各章の範囲」「Arban の合計」「全体の合計（45〜115分）」をすべてプログラムで検査し、違反があれば修正案を出します。
- 章ごとに分ける前に保存したメニュー（Arban 1項目）は、初期値に戻ります。以前の練習記録は「Arban（アーバン）」として表示されます。

## 3. 「今日の重点」のおすすめ（通常モード）

特定の奏者のメニューをそのまま写したものではなく、調査の考え方をルールの範囲で配分したものです（すべてルールを満たすことをテストで確認）。
どの案にも「曲・エチュード」を入れています。

| おすすめ | 合計 | 配分の考え方 |
|---|---:|---|
| バランス | 80分 | 初期値と同じ。Arban はスラー・音階・タンギング各10分、曲20分 |
| 短め（45分） | 45分 | 合奏・レッスンがある日。基礎を整え、曲は難所だけ（12分） |
| 音色・柔軟性 | 80分 | ロングトーン・リップスラーを厚く、Arban はスラーとフレージング |
| 指・音階 | 75分 | Arban の音階・半音階・音程跳躍 |
| タンギング | 75分 | Arban のタンギング20分＋初歩練習・シンコペーション |
| 表現・曲 | 85分 | Arban のフレージング・性格的練習曲・装飾音、曲25分 |
| 長め（105分） | 105分 | 基礎を維持しつつ Arban 40分・曲20分 |

## 4. 指示書のルールの見直し（運営の判断で反映済み）

調査と指示書のルールが食い違う点を運営に確認し、次のとおり変更しました。

| 提案 | 決定 | アプリでの扱い |
|---|---|---|
| 1. マウスピース 15〜30分はプロの例（4〜5分）より長い | 反映 | 「ウォームアップ（呼吸・バズィング）」3〜10分（初期値5分）。記録のキーは `mouthpiece` のまま |
| 2. 「曲・エチュード」の項目がない | 反映 | 最後の項目として 0〜40分（初期値20分）。おすすめにもすべて入れた |
| 3. 合計45分の下限が短い日に合わない | 反映 | 時間モード「通常（45〜115分）」「20分（15〜25分）」「10分（5〜15分）」 |
| 4. 合奏・本番の負荷と疲れ | 反映 | 「今日の予定と調子」から、時間モード・おすすめ・休息をすすめる（下表） |
| 5. 振り返り（録音） | Stage 3 | メモはすでに記録できる。録音は Stage 3 で扱う |
| 6. 練習を複数回に分ける | 現状で対応 | 1日に複数回記録しても集計できる |

「今日の予定と調子」のすすめ（上から順に当てはまったもの）：

| 条件 | すすめ | 根拠 |
|---|---|---|
| 唇が痛い | 吹かずに休む（続くときは指導者・医療機関に相談） | 疲労や痛みが出たら吹き続けない |
| 本番がある | 20分モード | 本番前は必要な準備だけ（Chris Martin） |
| 疲れている＋合奏 | 10分モード | 合奏も唇の負荷になる |
| 疲れている | 20分モード | 忙しい時期は量を減らす方が安定（Steve Hendrickson） |
| 合奏・レッスンがある | 通常モードの「短め（45分）」 | 合奏・本番も演奏時間に含まれる |
| 昨日たくさん吹いた | 通常モードの「音色・柔軟性」 | 高音・大音量の翌日は柔らかい音で（Brian Shaw） |
| どれでもない | いつもどおり | |

## 5. ローカル AI（Stage 2）への活かし方

- AI には「今日の重点」と、記録（直近7日の項目別の時間）を渡して、Arban の章の選び方や練習の言葉かけを提案させる。
- AI のメニュー案は、これまでどおり JSON で受け取り、プログラムの監査（章・Arban 合計・全体合計）を通らなければ採用しない。
