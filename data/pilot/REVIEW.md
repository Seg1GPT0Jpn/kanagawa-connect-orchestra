# パイロット（MVP）レビュー記録

対象: `data/pilot/` の 6 セット（5教科×各20問、5教科オリジナル模試 第1回 130問）と `output/pilot/` の PDF（A4・タブレット版）
実施日: 2026-10-10
方法: 自動検査（`validate_questions.py`）の結果確認、PDF 全ページの目視確認、問題内容の読み合わせ（作成者による確認）

> 注意: このレビューは作成者（AI）による確認です。各問題の `verification.status` は `auto_checked`（自動検査済み）であり、
> 教科担当者による内容レビュー（`expert_reviewed`）は未実施です。授業・配布で使う前に必ず専門家の確認を受けてください。

## 指摘事項と対応

| No. | 区分 | 指摘 | 対応 | 反映先 |
|---|---|---|---|---|
| R1 | 問題内容 | 英語の語順整序で、文頭の語だけ大文字になっており語順のヒントになる（PILOT-ENG-U01 Q013・Q014、模試 英 問4(イ)） | 文頭の語も小文字で示し、問題文に「文頭にくる語も小文字で示してある」と明記 | データ（版 1.1.0） |
| R2 | 検査 | `20\,^\circ` のような KaTeX で描画できない数式が、PDF ビルド時まで検出されなかった | `validate_questions.py` に LaTeX の簡易構文検査（波かっこ・`\left`/`\right`・空白命令直後の `^` など）を追加 | スクリプト |
| R3 | レイアウト | 解答解説冊子で「解説」ラベルが独立した行になり、余白が多い | ラベルと解説の1段落目を同じ行に組む | テンプレート |
| R4 | レイアウト | タブレット版で、長い選択肢が2段組のまま細かく折り返される | 用紙ごとに段組みの閾値を設定（A4・B5・タブレット） | `build_pdf.py` |
| R5 | レイアウト | 模試のリスニングで、放送文の案内枠が設問ごとに繰り返される | 同じ大問の2つ目以降は見出しのみの表示にする | テンプレート |
| R6 | レイアウト | 模試の解答冊子に教科別の配点合計がない | 解答冊子の冒頭に教科（大問）別の問題数・配点表を追加 | テンプレート |
| R7 | レイアウト | 模試の解答用紙で、記述問題の欄が選択問題と同じ高さで書ききれない | 記述・論述問題の行を高くする | テンプレート |
| R8 | レイアウト | 語順整序に解答欄がない | 並べ替え問題に解答欄を追加 | テンプレート |
| R9 | 文字化け | Noto CJK（OTF）が Type3 で埋め込まれ、PDF が大きくテキスト抽出も不安定 | TrueType の IPA フォントを優先し、疑似太字を無効化。PDF 検査で Type3 を警告 | テンプレート・`build_pdf.py` |
| R10 | 組版 | IPA フォント（等幅）で欧文が間延びする | 欧文フォントを先に指定し、和文は IPA フォントで表示 | テンプレート |

R9・R10・R8 はパイロット PDF の初回確定前に対応済み。R1〜R7 は本レビュー後に対応し、データの変更は各 JSON の `revision_history` に記録した。

## 量産（フェーズ2〜5）への申し送り

- 並べ替え問題は文頭の語も小文字で示す。
- 温度などの単位記号は `20\,{}^\circ\mathrm{C}` のように書く（検査で検出される）。
- 図は「右の図」ではなく「図」と書く（組版位置が一定でないため）。
- 解説では選択肢の記号（ア・イ…）を使わない（選択肢は出力時に並べ替えるため）。
- 統計・地図などの実データを使う場合は出典と年次を明記する。出典を確認できない数値は「架空の国」などの設定にする。
