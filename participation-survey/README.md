# 参加表明フォームの集計（Google Apps Script）

第1回演奏会の「参加表明」フォームの回答スプレッドシートに追加して使うスクリプトです。

- `参加表明集計.gs`：スクリプト本体（Apps Script エディタにまるごと貼り付けます）
- `test/run-tests.js`：ローカル検証（架空のデータだけを使用）。`node test/run-tests.js`

## 作るシート

| シート | 種類 | 内容 |
|---|---|---|
| 参加表明ダッシュボード | 自動生成 | 回答数・締切までの日数・パート別（目標人数との比較）・曜日・エリア・参加費（累積）・頻度 |
| 参加表明一覧 | 自動生成 | パート順（木管→金管→打楽器→弦）。見送る＝灰色、18歳未満で保護者の了承が未確認＝赤 |
| 未回答者リスト | 自動生成 | 団員応募の「応募者一覧」とメールアドレスで照合。BCC に貼れる宛先一覧つき |
| 運営お手伝い | 自動生成 | 役割ごとの名前 |
| 伝えておきたいこと | 自動生成 | 記入があった人だけ |
| データチェック | 自動生成 | 重複回答・パート判定不可・保護者の了承など |
| 集計設定 | 運営が書く | 団員応募スプレッドシートの URL・回答シート名・締切日・除く対応状況 |
| 手入力回答 | 運営が書く | フォーム以外（DM など）でもらった回答。列はフォームと同じ |
| 除外リスト | 運営が書く | 未回答者リストから外す人のメールアドレス |

## 安全のための約束

- フォームの回答シートと、団員応募スプレッドシートには書き込みません（読むだけ）
- 書き込むのは自動生成シートだけです（名前を確認してから書き込みます）
- メール送信・外部への送信は行いません
- 団員応募スプレッドシートの URL はコードに書かず、「集計設定」シートに書きます（このリポジトリは公開されているため）

## 必要な権限

`SpreadsheetApp.openById`（団員応募スプレッドシートを開く）は、Google の仕様で
「すべてのスプレッドシートの表示・編集」の権限（`https://www.googleapis.com/auth/spreadsheets`）が必要です。
コードは団員応募スプレッドシートを読むだけで、書き込みは行いません。
フォーム送信時の自動更新には、トリガーを管理する権限（`script.scriptapp`）も使います。
